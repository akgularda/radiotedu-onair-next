# Programme draft operator acceptance

This workflow reviews draft configuration only. It must not be described as qualified special-day playback. The `programme-drafts-v1` capability does not enable any event, retarget a live folder, change a queue, or authorize source takeover. Enabled drafts are rejected in the engine.

Use a compatible isolated engine. Keep the legacy production service and all existing source connections unchanged. Use Energize for the target station in the UI. Execute the following through visible controls, mouse and keyboard; API/unit checks cannot substitute for this acceptance.

1. Open the installed console and connect the matching engine in System. Select Schedule. Confirm the draft/not-on-air notice and Istanbul timezone are visible.
2. Create a special-day draft named `29 October review`, targeting only Energize. Choose October 29, 08:00–14:00, Finish Current Song entry, Finish Current Item return, annual recurrence, a local event music folder through Browse, and fixed display text `29 Ekim Özel`. Check the note about a return extending beyond the nominal end. Confirm ordinary jingle/sweeper files and cadence are retained, with no replacement controls.
3. Preview from October 29 midnight in Istanbul. Confirm the six-hour window, correct channel and transition policy. Change the start time; confirm the previous result is removed and a new preview is required. Changing settings while a preview is loading must not allow the old response to repopulate it.
4. Save draft and read it back from the list. Refresh, navigate away/back, and reopen the console. Confirm its version, folder, dates, order and display text persist and it remains disabled. Change unsaved text, refresh the browser and verify the local editor copy is recovered. A local copy is not an engine save or a backup.
5. With a deliberately unconfirmed save response in an isolated fixture, retry the same saved request. Confirm it produces the original revision, not a second revision. A different request using that command ID must be rejected. Do not induce network or service failure on production to run this check.
6. Create an additional timed sweeper draft for Energize. Browse to a local LÖSEV folder; test choosing the folder and choosing a single audio file. Configure its cadence/date range. Preview it with the special-day draft. Review the named overlaps and priority explanation. No insertion is played by this draft preview.
7. Edit the special-day end policy to Fade At Scheduled End. Save, inspect History, archive, then restore an earlier version as a new disabled draft. Confirm the actor, versions and archived history remain visible, and the normal station queue/cadence/history did not change.
8. Switch engines with an unsaved editor and with a picker/history dialog open. Confirm dialogs close, an old response cannot replace current data, and local editor recovery is engine-specific. Never infer that mouse acceptance passed from reading this checklist or from browser model tests.

Actual programme publication still requires prepared event media, persistent occurrence/position ownership, entry/return PCM transitions, normal branding-counter preservation during actual playout, metadata override/restoration across all codecs, missing-media fallback and restart/expiry qualification. Follow the staged group handover gates after these pass.
