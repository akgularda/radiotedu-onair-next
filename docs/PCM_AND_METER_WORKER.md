# Float programme audio and asynchronous metering

Exact source `e3b19c5b` passed scoped software and real loopback qualification in [run 38835930561](https://github.com/akgularda/radiotedu-onair-next/actions/runs/38835930561): 171 unit cases, 7 browser-model cases, 95 real audio checks across seven scenarios, 35 SCM checks, 20 setup checks and nine independent synthetic signal comparisons. All six evidence archive digests and execution source identities were verified. See [scoped evidence](../artifacts/evidence/float-meter-audio-171-20261016.json). The old broadcasting installation remains untouched. No station group has migrated, and no output is certified from a programme meter.

## Programme contract

The new engine transports interleaved little-endian IEEE float32 at 48 kHz stereo. A sample frame is 8 bytes; a full 20 ms block is 7,680 bytes. Decoder and persistent encoder pipe formats change together. All intra-block playback-event and item-position divisions use the shared frame size. Finite programme EOF publishes only its actual sample frames, without extra zero padding.

The microphone mixer preserves small signals and over-full-scale headroom instead of quantizing/clipping to 16 bits before final processing. Malformed/nonfinite microphone packets are rejected while music continues. The decoder rejects nonfinite asset PCM so normal failed-asset handling can select another approved item. This is not a true-peak limiter: the required normalization and final ceiling processor remain unfinished. Do not arm production destinations from this change.

Ogg FLAC requests `s32` input to its encoder and explicitly selects 24 raw bits. AAC-LC remains 192 kbps; HE-AACv2 remains libfdk_aac 64 kbps and is never substituted. The later physical audio agent must use the new complete float-frame contract; old 16-bit microphone blocks are rejected by their length. Actual device capture/cue/recording and all 18 production outputs remain separate gates.

## Bounded measurement worker

Each running station publishes its final music/microphone mix to a separate worker with a default queue of 40 blocks (800 ms, approximately 300 KiB of PCM). Publishing only retains/releases a pooled-block reference and attempts a nonblocking channel write. A stalled meter/history writer never holds the programme producer or output fanout. A full queue drops measurement coverage, not audio; counters and source-sample discontinuities are visible.

The worker owns one `StereoLoudnessMeter48k`. It publishes M/S/true-peak snapshots at 10 Hz and recomputes gated I/LRA at 1 Hz. Cheap live readings carry the separate sample position through which statistics were computed. Negligible K-filter state is cleared every 20 ms far below float32's signal floor to avoid denormal arithmetic after silence. Actual target-PC CPU/timing validation is still required.

Default continuous-service windows last one hour of programme samples, starting at the session's first measured sample rather than a calendar-hour boundary. Full windows roll at exact sample positions, even inside a partial caller block. Stop, gaps, invalid PCM and process restart are different end reasons. A gap closes the previous segment as incomplete; a new segment starts at the next known source position. No missing samples are synthesized into integrated loudness. These continuous-service windows do not yet implement scheduled programme ownership or normalization decisions.

The worker retains only its current and last closed snapshots, plus bounded energy/statistics arrays. History writes run outside the programme thread through the existing dedicated journal lane. Started, one-minute prefix and terminal snapshots are append-only, payload-hashed and bound to an immutable station/session/window identity. An exact retry is deduplicated; a changed payload or owner is rejected. On restart, an unfinished window keeps its latest known measured prefix and is marked interrupted with an unknown tail. It is not presented as a completed hour. The writer keeps at most one outstanding measurement write; timeouts/failures and skipped persistence are visible. Shutdown drains for at most two seconds, then releases remaining PCM references and marks lost coverage.

## Browser readout

Channel details contains the programme meter and paged saved history. Only the selected visible running station is polled at up to 10 Hz; requests cannot stack. The authenticated read endpoint has its own single-request admission gate and a short deadline. Closing/hiding the browser stops UI polling while the service keeps measuring.

Readouts distinguish encoder-input measurements from decoded-output verification. Unknown, stale, faulted and invalid-scope values are absent; statistics age is checked separately from live levels. LRA is withheld until the measurement has settled for at least one minute. Peaks above the linear ceiling, dropped coverage and incomplete history remain warnings. There is no compliance badge. Normalization/limiter controls are not implemented by a read-only meter.

## Qualification

Qualified tests cover sub-16-bit mic detail/stereo separation, unclipped mix headroom, invalid packets, exact partial EOF/window rollover, blocked history versus nonblocking producer, overflow/source-gap accounting, nonfinite PCM recovery, reference release, immutable saved prefixes and process-restart interruption. Browser model tests cover stale/future timestamps, statistical age, wrong scope, gaps, stopped/faulted state and absent values.

Disposable Windows CI now runs `Test-Engine.ps1 -PreparedCiBuild` through `Test-WindowsAudio.ps1`, using SHA-256-pinned real FFmpeg 9.0.2 and Icecast 2.5.0. It checks baseline, 24-bit stereo precision, synthetic live input, recovery, finite EOF, backpressure and corrupt assets. The precision case compares decoded Ogg FLAC against a deterministic 24-bit stereo input across file boundaries, verifies preserved sub-16-bit detail and independently reads codec/rate/channels/raw bit depth. Listener PCM stays in memory; only synthetic input fixtures and numerical evidence are written. This is not a recording of music or a private broadcast.

The first run at source `83c8ee7d` passed its 22 real baseline checks, but the wrapper miscounted an empty remaining-child dictionary and stopped the run; [that failed aggregation is retained](../artifacts/evidence/float-first-audio-wrapper-failure-20261016.json). The corrected complete run decoded 135,808 stereo FLAC frames with zero differing frames/zero 24-bit-LSB error; 135,805 frames retained sub-16-bit detail and both channels stayed distinct. Independent metadata confirmed 48 kHz, two channels and 24 raw bits. These results still do not prove HE-AAC, all 18 streams, target-PC hardware/resource behavior, normalization/true-peak limiting, microphone recording, connected mouse acceptance or 24/72-hour continuity. All commissioning gates in the delivery ledger remain open until independently proven.
