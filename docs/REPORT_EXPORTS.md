# Calendar report exports

Reports now has day/year selection, all-channel or one-channel scope, durable same-ID retry, cancellation, persisted receipts and CSV downloads. This implementation is awaiting fresh remote and connected-browser qualification. No production station or legacy database was changed.

The selection uses Europe/Istanbul calendar boundaries with an exclusive end. An annual export starts at Istanbul midnight on January 1 and ends at the next January 1, rather than using UTC year boundaries. The CSV retains actual started attempts, immutable artist/title metadata, terminal status when known, UTC/local timestamps, sample-clock duration, previous-attempt linkage and timing quality. Open attempts remain incomplete. Codec branches do not create duplicate attempts. List pagination applies only to export receipts, never to CSV rows.

A committed export request goes through the existing bounded FULL-WAL journal writer. One export runs at a time. A dedicated below-normal thread reads a consistent SQLite snapshot and writes at a bounded 1 MiB/s, keeping a 2 GiB free-space floor. SHA-256 accumulates during writing, avoiding a second full annual-file scan. A completed receipt retains the actual SQLite snapshot sequence/time, row and incomplete counts, exact byte length and digest. Original playback events and media are unchanged.

Cancellation is durable. A committed cancellation cannot be overwritten by a late completion. Restarted, unconfirmed jobs are marked interrupted; an explicit retry creates a new artifact attempt and preserves any prior unconfirmed file. Only confirmed completed artifacts are offered for download. A retry with another selection cannot reuse an existing export ID.

Downloads use a separate authenticated report pipe, leaving station controls and Library uploads independent. Installed clients verify the actual service process and the service verifies its operator. Anonymous callers receive no report bytes. The local HTTP download requires the authorized session cookie and a random single-use 30-second grant created through the normal CSRF-protected API. Expiry also uses monotonic time. The relay uses two 64 KiB buffers and verifies exact bytes/SHA-256 before releasing the final chunk; it does not load an annual report into a browser Blob. The service transfer is limited to 2 MiB/s and abandons stalled clients after five seconds without progress.

Focused regressions cover Istanbul year boundaries, station filtering, exact file hashes, restart/attempt preservation, cancellation races and partial-file cleanup, plus ticket binding/replay/expiry/bounds and counterfeit report servers. The real LocalService fixture adds report transfer, independent station/Library control and anonymous rejection checks. The full eighteen-codec fixture seeds 10025 synthetic archived attempts before audio, then exports and independently validates the complete annual CSV while all eighteen live listeners remain active. All existing codec, continuous PCM, meter-history, Stop and immutable-chain checks remain required.

Automatic Istanbul daily generation, private GitHub outbox/retry/catch-up, target-PC/connected mouse acceptance and full long-run release gates remain unfinished. No automatic external integration is activated by these local export controls.
